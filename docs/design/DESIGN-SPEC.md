# DESIGN-SPEC

각 화면에 무엇이 어떻게 놓이는지 정한다. 인상과 색, 타이포그래피, 컴포넌트의 생김새는 `DESIGN.md`가 정하고 기능의 동작 규칙은 `product/SPEC.md`가 정한다.

사이트는 화면 하나로 이루어진 정적 페이지다. 주소는 바뀌지 않고 콘텐츠 영역이 상태에 따라 업로드, 변환 확인, 변환 진행, 결과, 실패 안내의 다섯 모습으로 바뀐다. 지원하지 않는 브라우저에서는 이 흐름 대신 비지원 브라우저 안내 하나만 보여준다. 상태는 저장하지 않으므로 새로고침하면 업로드 화면부터 다시 시작한다.

## 공통 틀

- 헤더: 높이 72px, 좌우 여백 40px. 왼쪽에 말글 로고 이미지를 높이 28px로 놓고 그 옆에 "영상은 이 브라우저 밖으로 나가지 않습니다" 배지를 둔다. 아래에 선을 긋지 않는다
- 콘텐츠 영역: 좌우 여백 32px. 결과 화면만 최대 폭 1200px을 쓰고 위 40px 아래 64px을 둔다. 나머지 화면은 최대 폭 640px에 위 72px 아래 112px이다
- 푸터: 위에 `border` 1px 선을 긋고 좌우 40px 위아래 20px 여백에 "made by chan9yu"와 저장소 링크를 한 줄로 놓는다

헤더에 선을 긋지 않는 이유는 화면이 하나라서다. 이동할 곳이 없는 머리에 선을 그으면 한 장이어야 하는 화면이 두 조각으로 보인다. 푸터는 본문이 끝난 자리를 알려야 해서 선을 긋는다.

화면마다 제목과 그 아래 설명 한 줄이 바뀐다. 무엇을 하는 자리인지 제목이 먼저 말한다.

| 화면      | 제목               | 설명                                                       |
| --------- | ------------------ | ---------------------------------------------------------- |
| 업로드    | 영상을 텍스트로    | mp4와 mov 영상 속 한국어 음성을 이 브라우저 안에서 텍스트로 바꿉니다 |
| 변환 확인 | 이 영상을 변환할까요? | 시작하면 모든 처리가 이 브라우저 안에서 진행됩니다         |
| 변환 진행 | 변환하고 있어요    | 파일 이름                                                  |
| 실패 안내 | 변환하지 못했어요  | 없음                                                       |

제목과 설명 사이는 8px, 설명과 그 아래 내용 사이는 40px이다. 설명이 없는 실패 안내에서는 제목 아래가 곧 40px이다.

## 업로드 화면

640px 열에 위에서 아래로 놓는다.

1. 화면 제목과 설명
2. 업로드 영역: 높이 240px 상자. `surface` 바탕에 2px 점선 테두리, 반경 20px. 가운데에 "영상 파일을 여기에 끌어다 놓거나" 문구와 "파일 선택" 주 버튼을 20px 간격으로 세로로 쌓는다
3. 거절 안내문 자리: 업로드 영역에서 12px 아래. 거절이 없으면 비어 있다
4. 제한 안내: 보조 설명으로 "mp4, mov 파일 하나. 최대 1.9GB, 최대 2시간". 가운데 정렬하고 위 12px을 띄운다
5. 첫 사용 안내문: 위 32px을 띄운 일반 안내문. 저장된 모델이 이미 있으면 보여주지 않는다. 문구는 "첫 변환에는 음성 인식 모델 약 600MB를 내려받습니다. 다음부터는 저장된 모델로 바로 시작합니다."

거절 안내문이 제한 안내보다 위에 온다. 둘 다 업로드 영역 아래에 놓이는데, 방금 거절된 이유가 늘 있는 안내보다 먼저 눈에 들어와야 한다.

상태는 셋이다.

- 기본: 위 배치 그대로
- 드래그 중: 파일을 화면 위로 끌고 오면 업로드 영역이 `brand` 2px 실선 테두리와 `brand-soft` 바탕으로 바뀌고 문구가 "여기에 놓으면 업로드됩니다"로 바뀐다. 이 문구는 `brand-strong` 색 굵은 글자다
- 거절: 형식이나 크기, 길이 검사에 걸리면 업로드 영역 아래에 오류 안내문이 붙고 이유를 밝힌다. 영역 자체는 기본으로 돌아가 다른 파일을 바로 받을 수 있다

드래그 중에 문구를 바꾸는 이유는 테두리 색만으로는 무엇이 일어날지 말하지 않기 때문이다. 파일을 든 손이 화면 위에 있는 동안 놓아도 된다는 것을 글자로 알린다.

## 변환 확인 화면

파일이 검사를 통과하면 제목과 설명이 함께 바뀌고 업로드 영역 자리에 확인 카드가 온다. 변환 시작 전에 보여줘야 하는 소요 시간 안내가 이 화면의 존재 이유다.

카드는 `surface` 바탕에 반경 20px, 안쪽 여백 28px이다. 안에 위에서 아래로 놓는다.

1. 파일 정보: 왼쪽에 48px 정사각형 아이콘 자리를 두고 `brand-soft` 바탕에 반경 14px, 그 안에 영상을 뜻하는 단색 아이콘을 놓는다. 오른쪽에 파일 이름을 굵게, 그 아래 크기와 길이를 쉼표로 이어 `text-sub` 색으로 적는다
2. 소요 시간 안내문: 위 20px. 아이콘 없이 글자만 놓는 일반 안내문이다. 문구는 "긴 영상은 기기 성능에 따라 몇 분 이상 걸릴 수 있습니다"이고, 첫 사용이면 같은 상자에 " 첫 사용이라 음성 인식 모델 약 600MB를 내려받는 것이 먼저 진행됩니다"를 잇는다
3. 버튼 줄: 위 24px. "변환 시작" 주 버튼이 남은 폭을 다 쓰고 그 옆에 "다른 파일 선택" 보조 버튼을 12px 띄워 놓는다

이 안내문에만 아이콘을 두지 않는다. 카드 안에 이미 아이콘이 하나 있어 둘을 나란히 두면 어느 쪽을 봐야 할지 흐려진다.

주 버튼이 폭을 다 쓰는 이유는 이 화면에서 사용자가 할 일이 하나라서다. 두 버튼을 같은 폭으로 두면 되돌아가는 쪽이 시작하는 쪽과 같은 무게로 보인다.

## 변환 진행 화면

같은 640px 열이고 `surface` 카드 안에 놓는다. 카드 규격은 확인 화면과 같다.

1. 단계 목록: 모델 준비, 음성 추출, 변환 세 줄을 16px 간격으로 쌓는다. 각 줄은 10px 원과 이름으로 이루어진다. 지금 단계는 원을 `brand`로 채우고 이름을 굵게, 나머지는 원을 흰 바탕에 `border` 2px 테두리로 두고 이름을 `text-sub` 색으로 둔다
2. 진행률 막대: 위 28px. 높이 12px에 반경 999px, `border` 바탕에 `brand` 채움이다. 오른쪽에 고정폭 숫자로 수치를 적고 16px을 띄운다. 모델 다운로드 중에는 "312MB / 600MB"처럼 내려받은 용량을, 나머지 단계에서는 백분율을 보여준다

끝난 단계를 따로 표시하지 않는다. 세 단계가 순서대로 지나가고 진행률 막대가 얼마나 왔는지 말하므로 원 세 개가 어디까지 끝났는지까지 겹쳐 말할 필요가 없다.

중단 버튼은 두지 않는다. PRD에 없는 동선이고 잘못 올린 파일은 새로고침으로 처음부터 다시 하면 된다. 모든 처리가 기기 안이라 새로고침해도 잃는 것은 시간뿐이다.

## 결과 화면

콘텐츠 폭 1200px을 좌우 2단으로 나누고 사이를 32px 띄운다. 이 화면에는 제목을 두지 않는다. 결과가 곧 내용이라 제목이 차지할 자리를 문장 목록에 준다.

이 화면만 창을 스크롤하지 않는다. 헤더와 푸터 사이를 화면 높이에 맞춰 가두고 문장 목록만 자기 상자 안에서 움직인다. 그래서 플레이어와 도구 막대가 늘 같은 자리에 있다. 창이 스크롤되면 문장을 눌렀을 때 플레이어가 화면 밖에 있을 수 있다.

왼쪽 열은 폭 45%, 최소 420px이다.

1. 영상 플레이어: 16:9 비율에 반경 20px. 바탕은 `text` 색이고 브라우저 기본 컨트롤을 쓴다
2. 파일 이름과 길이: 위 12px. 파일 이름을 보조 설명 크기로 굵게, 그 옆에 전체 길이를 고정폭 숫자로 적는다

오른쪽 열에 도구 막대와 문장 목록을 세로로 쌓는다. 왼쪽부터 "전체 복사" 주 버튼, txt와 srt, vtt 내려받기 보조 버튼 셋을 8px 간격으로 놓고 오른쪽 끝에 "새 영상 변환" 보조 버튼을 둔다. 도구 막대의 버튼은 본문 버튼보다 작고 반경도 12px이다.

내려받기 버튼의 라벨은 "txt"와 "srt", "vtt"다. 셋이 나란히 있어 공통 동사가 배치로 드러나므로 "내려받기"를 세 번 반복하지 않는다. 다만 화면 낭독기는 배치를 읽지 못하므로 각 버튼에 "txt 내려받기" 형태의 대체 라벨을 붙인다.

"전체 복사"를 누르면 버튼 라벨이 2초 동안 "복사했습니다"로 바뀌었다가 돌아온다. 복사에 실패하면 같은 자리에 "복사하지 못했습니다"가 나온다. 클립보드 접근은 권한이나 보안 컨텍스트 때문에 실패할 수 있고, 알림이 없으면 눌러도 화면이 그대로라 됐는지 알 방법이 없다. 라벨이 바뀌는 동안 버튼 폭이 흔들리지 않게 한다. 결과에서 다음 변환으로 가는 길이 없으면 새로고침뿐이라 이 버튼 하나를 둔다. 결과는 저장되지 않으므로 누르면 지금 결과가 사라진다.

문장이 하나도 없으면 목록 자리에 일반 안내문을 놓는다. 오류가 아니라 정상으로 끝난 변환이라 오류 안내문을 쓰지 않는다. 이때 "전체 복사"와 내려받기 셋은 비활성이고 "새 영상 변환"만 살아 있다.

문장 목록의 각 행은 왼쪽 80px 열의 타임스탬프와 오른쪽 문장으로 이루어지고 사이를 16px 띄운다. 행의 안쪽 여백은 위아래 10px 좌우 16px이고 반경은 12px이다. 행 사이는 2px만 띄우고 구분선은 긋지 않는다. 마우스를 올리면 `surface` 바탕이 되고, 지금 재생 중인 구간의 행은 `brand-soft` 바탕에 타임스탬프가 `brand-strong` 색, 문장이 중간 굵기로 바뀐다. 행 전체가 클릭 대상이고 클릭하면 플레이어가 그 문장의 시작 시각부터 재생한다.

재생 중인 행에 색만 주지 않고 글자 굵기까지 바꾸는 이유는 목록이 길어서다. 수백 행 가운데 하나를 찾을 때 옅은 바탕색 하나로는 눈에 걸리지 않는다.

## 비지원 브라우저 안내

헤더와 푸터는 그대로 두고 콘텐츠 영역의 640px 열에 안내만 놓는다.

1. 화면 제목 "이 브라우저에서는 쓸 수 없습니다"
2. 그 아래 설명 "데스크톱 Chrome이나 Edge 최신 버전으로 열어 주세요"
3. 본문으로 "영상을 서버에 올리지 않고 브라우저 안에서만 처리하는 방식이라 이 브라우저들이 필요합니다"

업로드 영역을 비롯한 다른 요소는 보여주지 않는다.
