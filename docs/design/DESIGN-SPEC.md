# DESIGN-SPEC

각 화면에 무엇이 어떻게 놓이는지 정한다. 인상과 색, 타이포그래피, 컴포넌트의 생김새는 `DESIGN.md`가 정하고 기능의 동작 규칙은 `product/SPEC.md`가 정한다.

사이트는 화면 하나로 이루어진 정적 페이지다. 주소는 바뀌지 않고 콘텐츠 영역이 상태에 따라 업로드, 변환 확인, 변환 진행, 결과, 실패 안내의 다섯 모습으로 바뀐다. 지원하지 않는 브라우저에서는 이 흐름 대신 비지원 브라우저 안내 하나만 보여준다. 상태는 저장하지 않으므로 새로고침하면 업로드 화면부터 다시 시작한다.

## 공통 틀

- 헤더: 높이 64px. 왼쪽에 vidscript 워드마크, 그 옆에 "영상은 이 브라우저 밖으로 나가지 않습니다" 한 줄(보조 설명 크기, `text-sub`). 아래에 `border` 1px 선을 긋는다
- 콘텐츠 영역: 최대 폭 1200px을 가운데 정렬하고 좌우 여백 32px을 둔다. 결과 화면만 이 폭을 다 쓰고 나머지 상태는 그 안에서 폭 640px의 가운데 열을 쓴다
- 푸터: 만든 사람과 저장소 링크 한 줄. 위에 `border` 1px 선

## 업로드 화면

640px 가운데 열에 위에서 아래로 놓는다.

1. 화면 제목 "영상을 텍스트로". 그 아래 보조 설명 "mp4와 mov 영상 속 한국어 음성을 이 브라우저 안에서 텍스트로 바꿉니다"
2. 업로드 영역: 높이 240px 상자. `surface` 바탕에 점선 테두리. 가운데에 "영상 파일을 여기에 끌어다 놓거나" 문구와 "파일 선택" 주 버튼을 세로로 쌓는다
3. 제한 안내: 상자 바로 아래 보조 설명으로 "mp4, mov 파일 하나. 최대 2GB, 최대 2시간"
4. 첫 사용 안내문: `brand-soft` 바탕 상자. 첫 변환 때 음성 인식 모델 약 600MB를 내려받고 다음부터는 저장된 모델로 바로 시작한다는 내용. 저장된 모델이 이미 있으면 보여주지 않는다

상태는 셋이다.

- 기본: 위 배치 그대로
- 드래그 중: 파일을 화면 위로 끌고 오면 업로드 영역이 `brand` 실선 테두리와 `brand-soft` 바탕으로 바뀐다
- 거절: 형식이나 크기, 길이 검사에 걸리면 업로드 영역 아래에 `danger-soft` 안내문이 붙고 이유를 밝힌다. 영역 자체는 기본으로 돌아가 다른 파일을 바로 받을 수 있다

## 변환 확인 화면

파일이 검사를 통과하면 업로드 영역 자리가 확인 카드로 바뀐다. 변환 시작 전에 보여줘야 하는 소요 시간 안내가 이 화면의 존재 이유다.

1. 파일 정보: 파일 이름과 크기, 영상 길이를 본문 크기로
2. 소요 시간 안내문: `brand-soft` 바탕. 긴 영상은 기기 성능에 따라 몇 분 이상 걸릴 수 있다는 내용. 첫 사용이면 모델 다운로드가 먼저 진행된다는 내용을 같은 상자에 잇는다
3. 버튼 줄: "변환 시작" 주 버튼과 "다른 파일 선택" 보조 버튼을 나란히

## 변환 진행 화면

같은 640px 열이다.

1. 파일 이름을 보조 설명 크기로
2. 단계 목록: 모델 준비, 음성 추출, 변환 세 줄. 끝난 단계는 `brand` 색 완료 표시를 앞에 붙이고 지금 단계는 `text` 색 굵은 글자, 아직 안 온 단계는 `text-sub` 색으로 둔다
3. 진행률 막대: `border` 바탕에 `brand` 채움. 오른쪽에 백분율 숫자. 모델 다운로드 중에는 "312MB / 600MB"처럼 내려받은 용량을 백분율 대신 보여준다

중단 버튼은 두지 않는다. PRD에 없는 동선이고 잘못 올린 파일은 새로고침으로 처음부터 다시 하면 된다. 모든 처리가 기기 안이라 새로고침해도 잃는 것은 시간뿐이다.

## 결과 화면

콘텐츠 폭 1200px을 좌우 2단으로 나눈다.

- 왼쪽 열: 폭 45%, 최소 420px. 영상 플레이어를 16:9 비율로 놓고 브라우저 기본 컨트롤을 쓴다. 문장 목록을 스크롤해도 플레이어는 헤더 아래에 고정되어 따라온다. 문장을 클릭했을 때 플레이어가 항상 보여야 하기 때문이다
- 오른쪽 열: 도구 막대와 문장 목록을 세로로 쌓는다

도구 막대는 문장 목록 위에 한 줄로 놓고 목록을 스크롤해도 위에 고정한다. 왼쪽부터 "전체 복사" 주 버튼, txt와 srt, vtt 내려받기 보조 버튼 셋. 오른쪽 끝에 "새 영상 변환" 보조 버튼을 둔다. 결과에서 다음 변환으로 가는 길이 없으면 새로고침뿐이라 이 버튼 하나를 둔다. 결과는 저장되지 않으므로 누르면 지금 결과가 사라진다.

문장 목록의 각 행은 왼쪽 80px 열의 타임스탬프(고정폭 숫자, `text-sub`)와 오른쪽 문장(16px, 행간 1.8)으로 이루어진다. 행 사이 구분선은 긋지 않고 여백으로 가른다. 마우스를 올리면 `surface` 바탕, 지금 재생 중인 구간의 행은 `brand-soft` 바탕이다. 행 전체가 클릭 대상이고 클릭하면 플레이어가 그 문장의 시작 시각부터 재생한다.

## 실패 안내 화면

변환이 시작된 뒤의 실패를 다룬다. 업로드 단계의 거절은 업로드 화면 안의 상태이고 이 화면까지 오지 않는다.

640px 열에 둘만 놓는다.

1. `danger-soft` 안내문: 무엇이 실패했고 왜인지. 예를 들어 "이 파일에서 음성을 찾지 못했습니다"
2. "다른 파일 선택" 주 버튼

## 비지원 브라우저 안내

헤더와 푸터는 그대로 두고 콘텐츠 영역의 640px 열에 안내만 놓는다.

1. 화면 제목 "이 브라우저에서는 쓸 수 없습니다"
2. 본문: 데스크톱 Chrome이나 Edge 최신 버전으로 열어 달라는 안내와, 영상을 서버에 올리지 않고 브라우저 안에서만 처리하는 방식이라 이 브라우저들이 필요하다는 이유 한 줄

업로드 영역을 비롯한 다른 요소는 보여주지 않는다.

## 상태 전이

| 지금 상태 | 계기                                      | 다음 상태               |
| --------- | ----------------------------------------- | ----------------------- |
| 업로드    | 파일이 형식과 크기, 길이 검사를 통과한다  | 변환 확인               |
| 업로드    | 파일이 검사에 걸린다                      | 업로드 (거절 이유 표시) |
| 변환 확인 | "변환 시작"을 누른다                      | 변환 진행               |
| 변환 확인 | "다른 파일 선택"을 누른다                 | 업로드                  |
| 변환 진행 | 모델 준비와 음성 추출, 변환이 모두 끝난다 | 결과                    |
| 변환 진행 | 음성 추출이나 변환이 실패한다             | 실패 안내               |
| 결과      | "새 영상 변환"을 누른다                   | 업로드                  |
| 실패 안내 | "다른 파일 선택"을 누른다                 | 업로드                  |

비지원 브라우저 안내는 접속 시점에 판별해 들어가는 화면이고 거기서 다른 상태로 가는 전이는 없다.
