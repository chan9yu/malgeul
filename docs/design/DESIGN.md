# DESIGN

말글이 어떤 인상을 주는지 정한다. 원칙과 색, 타이포그래피, 컴포넌트 목록까지가 이 문서의 몫이고 각 화면에 무엇이 어떻게 놓이는지는 `DESIGN-SPEC.md`가 정한다.

## 인상

조용한 작업 도구. 회의 녹화처럼 민감한 파일을 맡기는 자리이니 화려함보다 차분한 신뢰가 먼저다. 흰 바탕과 회색 글자로 절제된 화면을 만들고 초록 한 색만 얹는다. 마케팅 사이트가 아니라 사무실에서 매일 쓰는 문서 도구에 가까운 얼굴이다.

## 디자인 원칙

제품 정체성인 프라이버시와 심플함에서 나왔다.

1. **프라이버시를 문구가 아니라 화면으로 보여준다.** 영상이 기기 밖으로 나가지 않는다는 약속이 이 제품의 존재 이유다. 첫 화면에 이 약속을 한 줄로 밝히고, 업로드부터 변환까지 모든 단계가 브라우저 안에서 도는 모습을 진행 표시로 드러낸다.
2. **텍스트가 주인공이다.** 이 제품의 결과물은 텍스트다. 장식과 그림자, 배경 무늬를 걷어내고 그 여력을 글자 크기와 행간, 대비에 쓴다.
3. **기다림을 정직하게 보여준다.** 모델 다운로드와 변환은 몇 분씩 걸린다. 지금 어느 단계인지와 얼마나 진행됐는지를 숨기지 않고 보여주면 긴 대기도 멈춘 것처럼 보이지 않는다.
4. **한 번에 한 가지 일만 시킨다.** 업로드, 변환, 결과의 세 상태가 한 화면에서 순서대로 바뀐다. 각 상태에서 사용자가 할 일은 하나뿐이고 주 버튼도 하나만 둔다.
5. **데스크톱의 폭을 쓴다.** 지원 대상이 데스크톱 Chrome과 Edge뿐이니 좁은 화면 대응에 힘을 빼지 않는다. 결과 화면은 영상 플레이어와 문장 목록을 좌우 2단으로 나란히 놓는 넓은 배치를 기본으로 잡는다.

## 색

브랜드 색은 짙은 초록이다. 초록은 안전하다는 신호로 읽히는 색이라 영상이 밖으로 나가지 않는다는 약속과 맞는다. 화면 대부분은 흰 바탕과 회색 글자로 두고 초록은 행동을 부르는 자리에만 쓴다. 이름은 코드에서 그대로 색 토큰으로 쓴다.

| 역할                                                         | 이름           | 값        |
| ------------------------------------------------------------ | -------------- | --------- |
| 브랜드 색. 주 버튼과 링크, 진행률 막대                       | `brand`        | `#0d7a5c` |
| 브랜드 색의 마우스 올림과 누름 상태                          | `brand-strong` | `#0a5f48` |
| 브랜드 색의 옅은 바탕. 재생 중 문장 하이라이트와 안내문 배경 | `brand-soft`   | `#e6f4ef` |
| 본문 글자                                                    | `text`         | `#1b1f23` |
| 보조 글자. 설명과 타임스탬프                                 | `text-sub`     | `#5c6670` |
| 바탕                                                         | `bg`           | `#ffffff` |
| 옅은 바탕. 업로드 영역과 문장 목록의 면 구분                 | `surface`      | `#f5f8f7` |
| 테두리                                                       | `border`       | `#e2e8e5` |
| 오류. 파일 거절 이유와 변환 실패 안내                        | `danger`       | `#c2483f` |
| 오류의 옅은 바탕                                             | `danger-soft`  | `#fbefee` |

`brand`와 `text-sub`, `danger`는 흰 바탕 위에서 대비 4.5:1을 넘겨 본문 크기 글자로 써도 된다.

첫 버전은 라이트 테마만 만든다. 테마 선택지는 지금 심플함보다 값어치가 없고, 어두운 방에서 강의 영상을 보는 사용자가 실제로 확인되면 그때 다크 테마를 검토한다.

## 타이포그래피

웹폰트는 Pretendard 하나만 쓴다. 한국어 화면에서 가장 널리 검증된 글꼴이고 고정폭 숫자(tabular figures)를 지원해 타임스탬프용 고정폭 폰트를 따로 들이지 않아도 된다. 타임스탬프에는 `font-variant-numeric: tabular-nums`를 건다.

폰트 파일은 외부 CDN에서 받지 않고 woff2 서브셋을 사이트 자원으로 함께 배포한다. 개발자 도구 네트워크 탭에서 외부 요청이 보이지 않아야 아무것도 나가지 않는다는 인상이 지켜진다.

폴백 스택은 `Pretendard, 'Apple SD Gothic Neo', 'Malgun Gothic', sans-serif`다.

| 용도                  | 크기 | 굵기 | 행간 |
| --------------------- | ---- | ---- | ---- |
| 화면 제목             | 32px | 700  | 1.4  |
| 절 제목               | 24px | 700  | 1.5  |
| 본문과 변환 결과 문장 | 16px | 400  | 1.8  |
| 목록 항목             | 16px | 400  | 1.5  |
| 머리말 설명           | 15px | 400  | 1.6  |
| 보조 설명             | 14px | 400  | 1.6  |
| 타임스탬프            | 13px | 500  | 1.8  |

한글은 글자 속이 차 있어 같은 크기의 영문보다 행간을 넉넉히 잡아야 읽기 편하다. 변환 결과는 긴 글을 이어 읽는 자리라 본문 행간을 1.8로 둔다.

본문과 목록 항목은 크기가 같고 행간만 다르다. 이어 읽는 글은 1.8로 벌리고 파일 이름이나 단계 이름처럼 한 줄로 끝나는 것은 1.5로 붙인다. 같은 1.8을 주면 한 줄짜리 항목 위아래에 쓰이지 않는 여백이 붙는다.

자간은 전체에 -0.01em을 걸고 화면 제목과 절 제목만 -0.02em으로 더 좁힌다. 큰 글자는 같은 자간에서도 더 벌어져 보인다.

## 면과 간격

간격은 4px 배수를 쓴다. 대부분은 8px 배수로 떨어지지만 버튼 여백 14px과 안내문 18px, 문장 행 10px처럼 그 사이가 필요한 자리가 있어 기준을 4px로 잡는다.

모서리 반경은 자리마다 다르고 이름으로 구분한다. 작은 것에 큰 반경을 주면 모서리가 둥근 알약처럼 보이고, 큰 면에 작은 반경을 주면 각져 보인다.

| 용도                              | 이름     | 값    |
| --------------------------------- | -------- | ----- |
| 문장 행과 도구 막대 버튼          | `row`    | 12px  |
| 버튼                              | `button` | 14px  |
| 안내문                            | `callout` | 16px  |
| 카드와 업로드 상자                | `card`   | 20px  |
| 배지와 진행률 막대, 단계 도트     | `pill`   | 999px |

그림자와 그라데이션은 쓰지 않는다. 면 구분은 `border` 테두리와 `surface` 바탕색으로 한다. 강조가 필요한 순간은 드래그 중인 업로드 영역처럼 브랜드 색 테두리로 만든다.

## 컴포넌트 목록

PRD의 기능 요구사항에서 나온 것과 DESIGN-SPEC의 공통 틀에서 나온 것을 함께 적는다. 여기서는 각 컴포넌트의 역할과 상태를 정하고 배치는 `DESIGN-SPEC.md`가 정한다. 코드의 컴포넌트 이름은 이 목록의 이름을 영어로 옮긴 것이라 문서와 코드를 오가며 찾을 수 있다.

### 앱 틀

헤더와 콘텐츠 영역, 푸터를 세로로 쌓는 바깥 상자다. 어떤 상태에서도 이 셋은 그대로 있고 가운데만 바뀐다. 콘텐츠 영역의 폭도 여기서 정한다. 결과 화면은 넓은 폭, 나머지는 640px 열이다.

화면 아무 데나 파일을 떨어뜨렸을 때 브라우저가 그 파일을 열어 지금 화면을 버리는 기본 동작도 여기서 막는다. 업로드 영역이 아닌 곳에 떨어뜨리는 일이 실제로 잦고, 변환 중에 그렇게 되면 몇 분 걸린 작업이 사라진다.

### 화면 제목

화면 제목과 그 아래 설명 한 줄이다. 어느 화면인지에 따라 둘 다 바뀌고 설명은 없을 수도 있다. 화면마다 무엇을 넣는지는 `DESIGN-SPEC.md`의 표에 있다.

### 버튼

주 버튼은 `brand` 바탕에 흰 글자로 굵게, 보조 버튼은 바탕만 두고 테두리를 두지 않는다. 마우스 올림과 누름에서 주 버튼은 `brand-strong`으로, 보조 버튼은 `border` 색으로 바뀐다. 비활성은 투명도 0.45다. 한 화면에 주 버튼은 하나만 둔다.

보조 버튼의 바탕은 놓이는 면에 따라 뒤집힌다. 흰 바탕 위에서는 `surface`, `surface` 카드 위에서는 흰색이다. 같은 색을 같은 색에 얹으면 버튼이 면과 구별되지 않는다.

크기는 둘이다. 본문 버튼은 반경 14px에 여백 14px과 28px, 도구 막대 버튼은 반경 12px에 더 좁다. 도구 막대에는 버튼 다섯 개가 한 줄에 들어가야 한다.

색 값은 코드와 글자 단위로 대조하므로 hex를 소문자로 적는다. Prettier가 CSS의 hex를 소문자로 바꿔서 대문자로 두면 문서와 코드가 어긋난다.

### 배지

헤더의 프라이버시 문구를 담는 알약 모양 상자다. `surface` 바탕에 `text-sub` 색 13px 중간 굵기 글자를 넣는다. 로고 옆에 붙어 이 사이트가 무엇을 약속하는지 첫 화면부터 말한다.

### 안내문

20px 아이콘과 14px 본문으로 이루어진 상자다. 일반 안내는 `brand-soft` 바탕, 오류는 `danger-soft` 바탕에 `danger` 색 글자다.

아이콘은 같은 원을 쓰고 안쪽 획의 위아래만 뒤집는다. 일반 안내는 아래가 긴 i, 오류는 위가 긴 느낌표가 된다. 획은 안내문 바탕색으로 파내 색을 두 가지만 쓴다.

카드 안처럼 이미 아이콘이 있는 자리에서는 아이콘 없이 글자만 놓는다.

### 비지원 브라우저 안내

데스크톱 Chrome과 Edge가 아닌 브라우저에서 접속하면 업로드 영역 대신 이 안내가 화면을 채운다. 지원 브라우저 이름을 밝히고 다른 기능은 보여주지 않는다.

### 헤더

왼쪽에 말글 로고 이미지를 높이 28px로 놓고 그 옆에 프라이버시 배지를 둔다. 메뉴는 없다. 로그인이 없고 화면도 하나뿐이라 이동할 곳이 없다.

로고는 한글 "말글" 워드마크를 그린 이미지 파일이다. 한국어 음성만 다루는 도구라 대상 사용자가 뜻을 바로 읽는다. 로마자 `malgeul`은 저장소와 패키지, 배포 경로처럼 기술 식별자가 필요한 자리에만 쓴다.

이미지는 화면에 놓이는 크기에 맞춘 해상도로 내보낸다. 폰트 CDN을 거부한 제품에서 워드마크 하나가 가장 큰 정적 자산이 되면 앞뒤가 맞지 않는다.

### 업로드 영역

파일 선택 버튼과 끌어다 놓기를 함께 받는 높이 240px 상자다. 반경은 20px, 테두리는 2px다. 상태는 셋이다. 기본은 `surface` 바탕에 점선 테두리, 파일을 끌고 들어오면 `brand` 실선 테두리와 `brand-soft` 바탕에 문구까지 바뀌고, 형식이나 크기(최대 1.9GB), 길이(최대 2시간)를 넘겨 거절되면 오류 안내문이 상자 아래 붙는다.

### 진행 표시

단계 이름 셋과 진행률 막대를 `surface` 카드 안에 놓는다. 각 단계는 10px 원과 이름이다. 지금 단계만 원을 `brand`로 채우고 이름을 굵게 한다. 막대는 높이 12px 알약 모양으로 `border` 바탕에 `brand` 채움이고 오른쪽에 고정폭 숫자를 붙인다. 모델 다운로드가 있는 첫 사용에는 백분율 대신 내려받은 용량을 보여준다.

### 영상 플레이어

브라우저 기본 video 컨트롤을 그대로 쓴다. 16:9 비율에 반경 20px이고 바탕은 `text` 색이다. 영상이 16:9가 아니면 남는 자리가 생기는데 흰 바탕이면 그 자리가 페이지처럼 보여 영상 테두리가 사라진다. 문장 목록에서 문장을 클릭하면 그 시작 시각으로 이동해 재생한다.

### 문장 목록

변환 결과의 본체다. 각 행은 타임스탬프와 문장으로 이루어지고 타임스탬프는 `text-sub` 색의 고정폭 숫자다. 행은 반경 12px이고 사이는 2px만 띄운다. 상태는 기본과 마우스 올림, 현재 재생 구간 셋이다. 재생 구간 행은 `brand-soft` 바탕에 타임스탬프가 `brand-strong`, 문장이 중간 굵기로 바뀐다. 행 전체가 클릭 대상이다.

문장이 하나도 없으면 목록 자리에 일반 안내문이 들어간다. 오류가 아니라 정상으로 끝난 변환이라 오류 바탕을 쓰지 않는다.

### 결과 도구 막대

전체 텍스트 복사 버튼과 txt, srt, vtt 내려받기 버튼, "새 영상 변환" 버튼을 문장 목록 위에 한 줄로 놓는다. 복사가 가장 잦은 동작이라 주 버튼이고 나머지 넷은 보조 버튼이다. 다섯이 한 줄에 들어가야 해서 작은 크기를 쓴다.

복사를 누르면 버튼 라벨이 2초 동안 결과 문구로 바뀐다. 클립보드는 권한이나 보안 컨텍스트 때문에 실패할 수 있어 성공과 실패를 나눠 알린다. 라벨이 바뀌는 동안 버튼 폭이 흔들리지 않게 한다.

문장이 하나도 없는 결과에서는 전체 복사와 내려받기 버튼 넷을 비활성으로 두고 "새 영상 변환"만 살려 둔다.
