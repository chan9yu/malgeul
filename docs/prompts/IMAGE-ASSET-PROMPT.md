# IMAGE-ASSET-PROMPT

파비콘과 OG 이미지처럼 배포되는 이미지 파일을 받으려고 생성 도구에 넣는 프롬프트다. 결과물을 만들어 낸 입력이므로 고치지 않고 보존한다. 같은 이미지를 다시 받을 일이 생기면 해당 절의 본문을 그대로 넣는다. 새 이미지가 필요해지면 기존 절을 고치는 대신 새 절을 추가한다.

워드마크는 생성 대상이 아니다. 화면과 OG 이미지의 "말글" 글자는 별도 로고 파일 없이 Pretendard 굵은 글자로 직접 적는다.

## 파비콘 (public/favicon.svg)

```
말글의 파비콘을 SVG 코드로 만들어라. 말글은 영상 속 한국어 음성을 브라우저 안에서 텍스트로 바꿔 주는 웹 도구다.

- viewBox는 0 0 64 64
- 모서리가 둥근 정사각형(반경 14)을 #0D7A5C 단색으로 채운다
- 그 안에 흰색 면 요소 셋만 넣는다. 위쪽에 오른쪽을 향한 재생 삼각형 하나, 그 아래에 길이가 다른 가로 막대 둘. 영상이 텍스트 줄로 바뀐다는 뜻이다
- 삼각형과 막대는 stroke 없이 fill로만 그리고 막대 끝은 둥글게 한다
- 그라데이션과 그림자, 다른 색을 쓰지 마라
- 16px로 줄여도 세 요소가 뭉개지지 않게 여백을 넉넉히 잡아라
```

## OG 이미지 (public/og.png, 1200 x 630)

```
말글의 OG 이미지를 1200 x 630 크기로 만들어라. 말글은 영상 속 한국어 음성을 브라우저 안에서 텍스트로 바꿔 주는 웹 도구다. 링크 미리보기에 쓰인다.

- 바탕은 #FFFFFF 단색
- 왼쪽 절반에 글자를 세로로 쌓는다. 위에 "말글"를 #0D7A5C 색 굵은 산세리프(Pretendard 계열)로 크게, 아래에 "영상 속 한국어 음성을 브라우저 안에서 텍스트로"를 #1B1F23 색으로 한 줄
- 그 아래 작은 글씨로 "영상은 기기 밖으로 나가지 않습니다"를 #5C6670 색으로 한 줄
- 오른쪽 절반에 변환 결과 화면을 단순화한 그림을 넣는다. #F5F8F7 바탕에 #E2E8E5 테두리의 둥근 카드 하나. 카드 안에 문장 행 셋을 넣되 각 행은 왼쪽에 #5C6670 색 타임스탬프 글자, 오른쪽에 #1B1F23 색 가로 막대(문장을 뜻하는 자리 표시). 둘째 행만 #E6F4EF 바탕으로 강조한다
- 색은 위에 적은 여섯 가지만 쓴다. 사진과 그라데이션, 그림자, 이모지를 쓰지 마라
- 여백을 넉넉히 두고 요소를 수직 가운데에 정렬한다
```
