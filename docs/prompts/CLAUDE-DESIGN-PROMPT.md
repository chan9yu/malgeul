## 제품

vidscript는 한국어 대화가 담긴 영상을 올리면 그 내용을 텍스트로 뽑아 주는 웹사이트다. 모든 처리가 브라우저 안에서 끝나고 영상은 기기 밖으로 나가지 않는다. 서버와 로그인이 없고 데스크톱 Chrome과 Edge 전용이다.

인상은 조용한 작업 도구다. 회의 녹화처럼 민감한 파일을 맡기는 자리이니 화려함보다 차분한 신뢰가 먼저다. 마케팅 사이트가 아니라 사무실에서 매일 쓰는 문서 도구에 가까운 얼굴로 만들어라.

## 만들 것

HTML 파일 하나. CSS는 파일 안에 인라인으로 넣고 외부 자원을 불러오지 마라. 데스크톱 폭 1440px 기준이고 반응형은 필요 없다. 아래 일곱 화면 상태를 위에서 아래로 나열하고 각 상태 앞에 상태 이름을 작은 라벨로 붙여라.

1. 업로드 기본
2. 업로드 드래그 중
3. 업로드 거절 (2GB를 넘는 파일을 올린 경우)
4. 변환 확인
5. 변환 진행 (모델 다운로드 중)
6. 결과
7. 실패 안내

## 색

이 열 가지만 써라. 그림자와 그라데이션은 쓰지 마라.

- brand #0D7A5C : 주 버튼, 링크, 진행률 막대 채움
- brand-strong #0A5F48 : 주 버튼의 마우스 올림과 누름
- brand-soft #E6F4EF : 재생 중 문장 하이라이트, 일반 안내문 바탕
- text #1B1F23 : 본문 글자
- text-sub #5C6670 : 보조 글자, 타임스탬프
- bg #FFFFFF : 바탕
- surface #F5F8F7 : 업로드 영역과 면 구분
- border #E2E8E5 : 테두리
- danger #C2483F : 오류 글자
- danger-soft #FBEFEE : 오류 안내문 바탕

## 타이포그래피

font-family는 Pretendard, 'Apple SD Gothic Neo', 'Malgun Gothic', sans-serif로 지정해라. 폰트 파일은 넣지 말고 폴백으로 보이게 둔다.

- 화면 제목: 28px, 굵기 700, 행간 1.4, 자간 -0.02em
- 절 제목: 20px, 굵기 600, 행간 1.5
- 본문과 변환 결과 문장: 16px, 굵기 400, 행간 1.8
- 보조 설명: 14px, 굵기 400, 행간 1.6
- 타임스탬프: 13px, 굵기 500, font-variant-numeric: tabular-nums

## 면과 간격

간격은 8px 배수만 쓴다. 모서리 반경은 8px 하나로 통일한다. 면 구분은 border 테두리와 surface 바탕색으로만 한다.

## 공통 틀

- 헤더: 높이 64px. 왼쪽에 vidscript 워드마크(Pretendard 굵은 글자, text 색), 그 옆에 "영상은 이 브라우저 밖으로 나가지 않습니다"를 text-sub 색 14px로. 아래 border 1px 선
- 콘텐츠: 최대 폭 1200px 가운데 정렬, 좌우 여백 32px. 결과 화면만 이 폭을 다 쓰고 나머지는 폭 640px 가운데 열
- 푸터: "made by chan9yu"와 저장소 링크 한 줄, 위 border 1px 선

## 화면별 구성

업로드 기본: 화면 제목 "영상을 텍스트로", 보조 설명 "mp4와 mov 영상 속 한국어 음성을 이 브라우저 안에서 텍스트로 바꿉니다". 높이 240px 업로드 상자(surface 바탕, 점선 테두리) 가운데에 "영상 파일을 여기에 끌어다 놓거나" 문구와 "파일 선택" 주 버튼. 상자 아래 보조 설명 "mp4, mov 파일 하나. 최대 2GB, 최대 2시간". 그 아래 brand-soft 안내문 "첫 변환에는 음성 인식 모델 약 600MB를 내려받습니다. 다음부터는 저장된 모델로 바로 시작합니다."

업로드 드래그 중: 같은 화면에서 업로드 상자만 brand 실선 테두리와 brand-soft 바탕으로 바뀐 모습.

업로드 거절: 같은 화면에서 상자 아래에 danger-soft 안내문 "파일이 2GB를 넘습니다. 더 작은 파일을 올려 주세요."가 붙은 모습.

변환 확인: 업로드 상자 자리에 확인 카드. 파일 이름 "주간회의_0812.mp4"와 "1.2GB, 58분"을 본문 크기로. 그 아래 brand-soft 안내문 "긴 영상은 기기 성능에 따라 몇 분 이상 걸릴 수 있습니다." 버튼 줄에 "변환 시작" 주 버튼과 "다른 파일 선택" 보조 버튼.

변환 진행: 파일 이름을 보조 설명으로. 단계 목록 세 줄: "모델 준비"(지금 단계, 굵은 글자), "음성 추출"과 "변환"(text-sub). 진행률 막대는 border 바탕에 brand 채움 52%, 오른쪽에 "312MB / 600MB".

결과: 좌우 2단. 왼쪽 45%에 16:9 영상 플레이어 자리(어두운 회색 면으로 대신하고 가운데에 재생 단추 모양). 오른쪽에 도구 막대와 문장 목록. 도구 막대는 왼쪽부터 "전체 복사" 주 버튼, "txt", "srt", "vtt" 보조 버튼, 오른쪽 끝에 "새 영상 변환" 보조 버튼. 문장 목록은 행마다 왼쪽 80px에 타임스탬프, 오른쪽에 문장. 여덟 행 정도 넣고 세 번째 행을 재생 중 상태(brand-soft 바탕)로 표시해라. 더미 문장은 한국어 회의 발언으로 만들어라. 예: "00:00:12 지난주에 이야기한 일정부터 다시 확인하고 시작하겠습니다." "00:00:31 배포는 목요일로 잡는 게 좋겠습니다."

실패 안내: danger-soft 안내문 "이 파일에서 음성을 찾지 못했습니다. 영상에 오디오 트랙이 있는지 확인해 주세요."와 "다른 파일 선택" 주 버튼.
