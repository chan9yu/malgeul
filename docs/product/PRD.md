# PRD

말글은 한국어 대화가 담긴 영상을 올리면 그 내용을 텍스트로 뽑아 주는 웹사이트다. 모든 처리가 브라우저 안에서 끝나고 영상은 기기 밖으로 나가지 않는다.

## 누구의 어떤 문제를 푸는가

회의나 인터뷰, 강의를 녹화한 영상은 다시 볼 때 비용이 크다. 한 시간짜리 녹화에서 필요한 대목을 찾으려면 영상을 처음부터 돌려 봐야 하고, 내용을 기록으로 남기려면 들으면서 받아 적어야 한다.

기존 변환 서비스는 영상을 서버에 올려야 한다. 회의 녹화에는 회사 내부 정보가, 인터뷰에는 상대방의 개인 정보가 담겨 있어 외부 서버에 올리기 꺼려진다. 게다가 대부분 유료다.

말글은 이 문제를 브라우저 안에서 푼다. 영상에서 음성을 추출하고 텍스트로 바꾸는 모든 과정이 사용자 기기에서 일어난다. 서버가 없으니 무료이고, 업로드가 없으니 유출될 경로가 없다.

## 목표 사용자

1차 사용자는 만드는 사람 자신이다. 실제 회의와 강의 녹화를 텍스트로 바꿔 쓴다. 같은 문제를 가진 사람이라면 누구나 쓸 수 있게 공개하고, 로그인은 없다.

## 핵심 시나리오

1. 회의 녹화 정리. 한 시간짜리 회의 녹화 mp4를 올리고 타임스탬프 붙은 텍스트를 얻는다. 필요한 발언을 텍스트에서 찾고 문장을 클릭해 그 시점의 영상으로 확인한다.
2. 강의 복습. 강의 녹화를 올려 전체 내용을 텍스트로 훑고, srt 자막 파일로 내려받아 영상과 함께 본다.

## 기능 요구사항

### 업로드

- .mp4와 .mov 영상 파일 한 개를 받는다. 파일 선택과 끌어다 놓기를 모두 지원한다
- 최대 2GB, 최대 2시간까지 받는다. 넘으면 이유를 알려주고 거절한다
- 긴 영상은 기기 성능에 따라 몇 분 이상 걸릴 수 있다는 안내를 변환 시작 전에 보여준다

### 변환

- 음성을 한국어 텍스트로 바꾼다. 화자 구분 없이 시간순으로 나열한다
- 각 문장에 시작 시각이 붙는다
- 진행 상황(모델 준비, 음성 추출, 변환 진행률)을 화면에 보여준다
- 첫 사용 시 음성 인식 모델 약 600MB를 내려받는다. 내려받는 동안 진행률을 보여주고, 이후 방문에서는 저장된 모델을 써서 바로 시작한다

### 결과

- 타임스탬프 붙은 문장 목록과 영상 플레이어를 함께 보여준다
- 문장을 클릭하면 플레이어가 그 시점부터 재생된다
- 전체 텍스트 복사 버튼을 제공한다
- txt와 srt, vtt 파일로 내려받을 수 있다

### 실패 처리

- 지원하지 않는 브라우저에서 접속하면 지원 브라우저를 안내한다
- 음성을 추출할 수 없는 파일은 실패 이유를 알려준다

## 범위에서 제외하는 것

- 화자 분리. 누가 말했는지 구분하지 않는다
- 결과 텍스트 편집. 고칠 내용은 복사해서 밖에서 고친다
- 오디오 파일(mp3, m4a 등) 업로드
- 한국어 외 언어
- 로그인과 계정, 서버 저장, 변환 기록
- 데스크톱 Chrome과 Edge 외 브라우저, 모바일

## 제약

- 서버가 없는 정적 사이트다. 영상과 음성, 텍스트는 브라우저 밖으로 나가지 않는다
- 지원 브라우저는 데스크톱 Chrome과 Edge 최신 버전이다
- 변환 속도와 처리 가능한 영상 길이는 사용자 기기 성능에 달려 있다
- 엔진과 모델 등 세부 기술 결정은 `SPEC.md`의 기술 결정 기록에 적는다

## 성공 기준

1. 1시간짜리 실제 한국어 회의 녹화 mp4를 올려 타임스탬프 붙은 텍스트를 얻고, srt 파일로 내려받아 실제로 쓴다
2. 변환 과정에서 영상이 네트워크로 전송되지 않는다. 개발자 도구 네트워크 탭으로 확인할 수 있다
3. 두 번째 방문부터는 모델 다운로드 없이 바로 변환이 시작된다
